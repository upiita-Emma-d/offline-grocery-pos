# ADR-005 — English codebase, Spanish UI, network printing and single-laptop deployment

Status: accepted, 2026-09-29.

## Context

The project is going to be published on GitHub, so code and documentation should be readable by anyone. The people who operate the store only read Spanish. The store will run on a second-generation Intel Core i3 laptop, not on the development PC. The existing printer is an Epson TM-T88V on the local network.

## Decision

1. **Language split.** Code (identifiers, comments, commits), documentation and ADRs are English. Everything a store operator sees is Spanish: templates, messages, ticket text, error messages, product names and page URLs (`/caja/`, `/turnos/`). API paths are English (`/api/sales/`). Stored choice values are English (`cash`, `piece`) with Spanish labels.
2. **Production serving.** `runserver` is for development only. The laptop runs **waitress** (pure-Python WSGI server that works on Windows and Linux) with `POS_DEBUG=0`; **WhiteNoise** serves static files. Configuration lives in a `.env` file next to `manage.py`, generated by the install scripts and never committed.
3. **Install scripts** for Windows 10/11 (`scripts/windows/install.ps1`) and Linux (`scripts/linux/install.sh`) create the environment, `.env`, database and owner account, start the server at logon/boot and schedule a daily verified backup.
4. **Network printing.** ESC/POS over TCP port 9100 prints the sale ticket, the shift opening and the shift report. The cut uses `GS V 66` (feed to cutter). Accents use code page Windows-1252 (`ESC t 16`), verified on the TM-T88V. The store name, header and footer are editable in the UI.
5. **Laptop OS.** Python 3.12+ and Django 5.2 do not run on Windows 7. Supported: Windows 10/11 or a lightweight Linux (Linux Mint XFCE recommended for a 2nd-gen i3 with 4 GB of RAM).

## Consequences

- Git history was restarted when publishing, to exclude private references and store data. The previous Spanish history is kept locally only.
- New dependencies: `waitress` and `whitenoise` (both pure Python).
